# Arch/pacman packaging

Build from source:

```bash
makepkg -si
```

Or grab the prebuilt package from the [GitHub release](https://github.com/sendement/dlss-manager/releases)
and install it directly:

```bash
sudo pacman -U dlss-manager-*.pkg.tar.zst
```

Not in the AUR (yet) -- this is a personal tool, not a submitted/maintained
AUR package. If that changes, update this note.
